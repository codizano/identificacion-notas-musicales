# Mapa de aprendizaje: crear aplicaciones web

Esta guía es para empezar desde cero y aprender, paso a paso, a crear proyectos como esta aplicación de identificación de notas musicales. No hace falta aprender todo de una vez: lo importante es practicar y entender lo que vas haciendo.

## El recorrido, de un vistazo

**Preparar el entorno → HTML y CSS → JavaScript → Git → React → TypeScript → entender este proyecto → crear y publicar mejoras**

La inteligencia artificial puede acompañarte durante todo el camino, pero conviene intentar cada paso y revisar sus respuestas para aprender de verdad.

## 1. Familiarizarse con VS Code

Aprende a:

- Abrir una carpeta de proyecto y encontrar sus archivos.
- Usar el explorador, las pestañas y la terminal integrada.
- Editar y guardar archivos, buscar texto y deshacer cambios.
- Leer los mensajes de error y usar el panel de problemas.
- Instalar extensiones solo cuando sepas para qué las necesitas.

**Práctica:** abre este proyecto en VS Code, encuentra `src/App.tsx` y `src/App.css`, y localiza dónde se muestra el título y dónde se define su estilo.

## 2. Entender cómo funciona una página web

Aprende lo básico de:

- **HTML:** la estructura y el contenido de una página.
- **CSS:** colores, tamaños, espacios, diseño adaptable y estados visuales.
- **JavaScript:** variables, funciones, condiciones, listas y eventos.

**Práctica:** cambia un texto o un color de la aplicación y observa el resultado en el navegador.

## 3. Usar la terminal y ejecutar el proyecto

La terminal permite dar instrucciones al proyecto. Aprende qué hacen estos comandos:

- `npm install`: instala las dependencias del proyecto.
- `npm run dev`: inicia el servidor local para ver la aplicación mientras trabajas.
- `npm run build`: comprueba y prepara una versión de producción.
- `npm run lint`: busca algunos problemas en el código.

**Práctica:** inicia el proyecto, ábrelo en el navegador y cambia algo pequeño. El servidor suele reflejar los cambios automáticamente.

## 4. Guardar avances con Git

Git guarda el historial de los cambios y permite volver a versiones anteriores. Empieza por aprender:

- Qué son un repositorio, un cambio y una rama.
- Cómo revisar qué archivos cambiaron.
- Cómo crear mensajes de guardado (commits) claros.
- Cómo usar GitHub para respaldar y compartir un proyecto.

**Práctica:** antes de una modificación, revisa el estado del repositorio; después, compara los cambios para ver exactamente qué editaste.

## 5. Aprender React

React ayuda a construir interfaces a partir de piezas reutilizables llamadas **componentes**. Aprende:

- Componentes y propiedades (props).
- Cómo mostrar listas y responder a eventos.
- Estado para guardar información que cambia, como la respuesta seleccionada.
- Cómo dividir una interfaz en componentes pequeños.

**Práctica:** explora los componentes de `src/components/` y sigue el recorrido desde `src/App.tsx` hasta una parte visible de la página.

## 6. Aprender TypeScript

TypeScript añade tipos a JavaScript para detectar ciertos errores antes de ejecutar el programa. Aprende:

- Tipos simples: texto, números y valores verdadero/falso.
- Arreglos, objetos e interfaces.
- Cómo leer los errores del editor y corregirlos.

**Práctica:** busca cómo se describen los tipos en `src/types.ts` y observa cómo se usan en los componentes.

## 7. Explorar las herramientas de este proyecto

Cuando los fundamentos te resulten familiares, investiga:

- **Vite:** inicia el proyecto y prepara la aplicación para publicarla.
- **CSS adaptable:** permite que la interfaz funcione en distintos tamaños de pantalla.
- **VexFlow:** dibuja notación musical, como pentagramas y notas.
- **Pruebas y lint:** ayudan a detectar errores y mantener el código ordenado.

No necesitas memorizarlo todo. Aprende cada herramienta cuando una tarea concreta te dé un motivo para usarla.

## 8. Practicar con mejoras pequeñas

Elige una idea por vez y divídela en pasos:

1. Cambiar instrucciones o textos para que sean más claros.
2. Ajustar colores, tamaños o la vista en pantallas pequeñas.
3. Añadir una opción de dificultad o una nueva pregunta.
4. Mejorar los mensajes cuando la respuesta es correcta o incorrecta.
5. Revisar la aplicación con el comando de lint y crear una compilación.

Antes de cambiar código, piensa qué debería ocurrir. Después, prueba el cambio en el navegador y explica con tus propias palabras cómo funciona.

## Cómo aprender con inteligencia artificial

Puedes usar un asistente de IA para:

- Pedir explicaciones sencillas de un concepto o fragmento de código.
- Compartir un error y preguntar qué significa y cómo investigarlo.
- Pedir pistas o un plan antes de pedir una solución completa.
- Solicitar una revisión de tus cambios y posibles casos que probar.

Ejemplos de preguntas:

- «Explícame este componente como si recién estuviera aprendiendo React».
- «¿Qué significa este error? Dame una pista para encontrar la causa».
- «¿Qué archivos tendría que entender para cambiar este texto? No hagas el cambio todavía».
- «¿Cómo puedo probar que esta mejora funciona en pantallas pequeñas?».

**Buenos hábitos:** no aceptes código que no puedas explicar; prueba lo que sugiera la IA; pídele que señale qué archivos cambiaría y por qué; y no compartas contraseñas, claves privadas ni datos personales. La IA puede equivocarse, así que verifica sus respuestas en el proyecto.

## Señales de que vas avanzando

- Puedes abrir y ejecutar el proyecto sin seguir instrucciones a ciegas.
- Sabes encontrar el componente y los estilos de una parte de la interfaz.
- Puedes hacer una modificación pequeña y revisar su efecto.
- Entiendes los errores más comunes y sabes pedir ayuda con contexto.
- Puedes describir qué cambiaste y por qué.
