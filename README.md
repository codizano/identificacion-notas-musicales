# Identificación de Notas Musicales

Aplicación interactiva para identificar y aprender notas musicales en el pentagrama.

## Características

- Visualización interactiva del pentagrama
- Identificación de notas musicales
- Modos de intervalos en clave de sol y clave de fa para identificar dos notas y la distancia entre ellas
- Interfaz intuitiva y responsiva

## Tecnologías

- React
- TypeScript
- Vite
- CSS

## Instalación

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
